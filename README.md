# Omi Real-Time Audio & Transcript Bridge for Hermes Agent

Real-time HTTP + WebSocket bridge that streams raw 16kHz PCM16 audio and live transcripts from an **Omi wearable** into **Hermes Agent** (`~/omi/`).

## Features

- **Dynamic `[1s pre + 5s core + 1s post]` Sliding-Window STT (`gemini-3.8-flash`)**:
  - Scans `±0.8s` around the `5.0s` mark to cut inside the lowest-energy `100ms` micro-pause (breath/syllable valley) so words are never sliced in half.
  - Prepends `1.0s` of pre-overlap audio and appends `1.0s` of post-lookahead audio (`7.0s` total context window) with automatic n-gram boundary deduplication.
  - Built-in RMS silence gate (`rms < 80`) skips silent windows at `$0.00` API cost.
  - **8-Second Idle Tail Flush**: Automatically flushes the final sentence when the Omi wearable is powered off or goes out of range, and resets the pre-overlap buffer so the next session starts cleanly.
- **Triple Ingestion Support on Port `8787`**:
  1. **Raw Audio Bytes Webhook (`POST /omi?sample_rate=16000&uid=...`)**: Works even when Omi's 300-minute cloud transcription quota is exhausted.
  2. **Continuous WebSocket Streaming (`wss://<host>/omi`)**: Compatible with Omi's `Custom (Real-time streaming)` STT mode.
  3. **Real-Time Transcript JSON (`POST /omi`)**: Accepts Omi `segments` JSON arrays.
- **Live Browser Audio & Transcript Monitor (`GET /listen`)**:
  - Open `http://127.0.0.1:8787/listen` (or `https://<your-tailscale-host>/listen`) to hear the live 16kHz PCM16 stream and watch live transcripts in real time.
- **Proactive Research Integration**:
  - Rolling 90-second transcript windows trigger Hermes's `omi-research` webhook to proactively search papers, tools, repos, and speakers mentioned in live talks.

## Quick Start

### 1. Expose Port 8787 via Tailscale Funnel (HTTPS 443)
```bash
tailscale funnel --bg --https=443 http://127.0.0.1:8787
```

### 2. Start the Bridge
```bash
chmod +x ~/omi/start.sh
~/omi/start.sh
```

### 3. Configure the Omi Mobile App
1. Open **Settings -> Developer Settings -> Webhooks**.
2. Enable **Audio Bytes**:
   - **Endpoint URL:** `https://<your-tailscale-host>.ts.net/omi`
   - **Interval (seconds):** `5`
3. Tap **Save** in the top-right corner of the header bar.

## Logs & Output Files
- `~/omi/logs/omi_live_transcript.log` — Clean uniform live transcript (`[YYYY-MM-DD HH:MM:SS] <text>`)
- `~/omi/logs/omi_bridge.log` — HTTP/WebSocket request & STT status log
- `~/omi/omi_live_research.md` — Proactive research cards generated by Hermes Agent
